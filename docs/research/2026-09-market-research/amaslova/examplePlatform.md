# Adalo vs Draftbit

| Критерий | Adalo | Draftbit |
|---|---|---|
| **Создание UI** | Визуальный drag-and-drop. Холст как экран смартфона. Панель экранов слева, настройки справа. Адаптивный layout (телефон/планшет/компьютер). | Визуальный редактор + code editor. Компоненты перетаскиваются, но можно писать свои JSX-компоненты. |
| **Работа с данными** | Встроенная реляционная БД. Коллекции, свойства, связи. Визуально, как конструктор связей. | Нет встроенной БД. Подключение REST API, GraphQL, Supabase, Firebase, Airtable, Xano. |
| **Навигация** | Tab Bar, App Bar, Side Navigation, Top Navigation. Компоненты копируются вручную на каждый экран. | Stack Navigator, Tab Bar, Drawer Navigator. Настройка через компоненты. |
| **Действия** | Привязываются к компонентам. Триггеры: нажатие, отправка формы, загрузка экрана. Действия: создать/обновить/удалить запись, переход, вход/выход, push, Ask ChatGPT, Custom Action. | Действия настраиваются не по одному, а цепочкой шагов . Триггеры: нажатие, изменение, фокус на экране. Действия: переход, запрос к API, задать переменную, условие, своя функция. |
| **Условия** | Два вида: условие для действия (сработает или нет) и условие для видимости (показать или скрыть). Только одно условие на компонент, без «И/ИЛИ». | Условие как шаг в цепочке действий. Плюс условный показ компонентов. Логика гибче. |
| **Цепочки действий** | Несколько действий подряд, привязанных к одному триггеру. Отдельного редактора нет — просто список. | Визуальный редактор цепочек: блоки, стрелки, передача данных между шагами. |
| **Mobile preview** | Preview в браузере. Adalo Test App через QR-код. | Live Preview в редакторе. Draftbit Preview через QR-код. Симуляторы iPhone, Pixel, iPad. |
| **Нативные возможности** | Push-уведомления, камера, геолокация, карты, QR-сканер, подпись. Встроенный Ask ChatGPT. | Push через Expo или Firebase. Камера, геолокация, QR-сканер. AI-агенты (Claude, OpenAI, Gemini) — можно подключить свою подписку. |
| **Свой код** | Нет. Только визуальная сборка. | Есть. Можно писать код, добавлять свои компоненты, экспортировать проект. |
| **Сильные стороны** | Низкий порог входа. Встроенная БД. AI-генерация. Шаблоны. | Владение кодом (экспорт React Native). GitHub - экспорт кода в репозиторий. AI-агенты с BYOK. Гибкость данных. Шаблоны.|
| **Ограничения** | Нет экспорта кода. Нет кастомного кода. Ограниченная логика. Навигация копируется вручную. | Нужно знать React Native/JavaScript. Нет встроенной БД. Нельзя импортировать чужой GitHub-репозиторий. |

## Полезные идеи:
- Шаблоны для разных сфер бизнеса (основные экраны)
- AI-генерация 
- Список возможных вопросов AI-ассистенту
- Предпросмотр в браузере
- Адаптивный layout
- Workflow-редактор — визуальный конструктор цепочек действий (собираете логику из блоков, соединённых стрелками)
- Возможность написания кода (?)
