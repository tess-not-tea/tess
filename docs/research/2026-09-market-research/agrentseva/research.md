#### 1) Аджикинежаль

**Тип бизнеса:** сеть ресторанов кавказской кухни.

**Тип приложения:** мобильное приложение для заказа еды, доставки и программы лояльности.

Приложение позволяет пользователю просматривать меню, выбирать блюда, оформлять доставку или самовывоз, использовать скидки и бонусы, а также управлять личными данными и адресами. У ресторана есть несколько филиалов в Новосибирске, поэтому приложение также помогает выбрать заведение для заказа.
##### **Основные пользовательские сценарии**
- **Просмотр меню и выбор блюд**  
    Пользователь открывает приложение, просматривает категории меню и выбирает интересующие блюда. В карточке блюда можно посмотреть фотографию, описание, цену и доступные добавки.
- **Оформление заказа с доставкой**  
    Пользователь выбирает блюда → добавляет их в корзину → выбирает способ получения **«Доставка»** → указывает адрес доставки → выбирает способ оплаты → подтверждает заказ. Приложение может использовать геолокацию для определения местоположения и упрощения ввода адреса.
- **Оформление заказа с самовывозом**  
    Пользователь выбирает блюда → добавляет их в корзину → выбирает **«Самовывоз»** → выбирает ресторан, из которого будет забирать заказ → оформляет и оплачивает заказ → приходит в выбранный ресторан и забирает готовую еду. 
- **Использование программы лояльности**  
    Пользователь открывает раздел с кэшбэком и видит свой текущий процент, прогресс до следующего уровня и доступный QR-код. Кэшбэк и накопленные преимущества можно использовать при последующих заказах.
- **Получение и использование персональных предложений**  
    Пользователь получает уведомления о скидках, подарках и специальных предложениях. Например, приложение может предложить персональную скидку ко дню рождения. Пользователь может перейти из уведомления к соответствующему предложению.
- **Управление личными данными**  
    Пользователь может просматривать и изменять свои данные, сохранять адреса доставки и управлять привязанными банковскими картами.
- **Просмотр истории заказов**  
    Пользователь открывает раздел **«Заказы»**, где может посмотреть свои предыдущие заказы и информацию о них.

##### **Основные экраны**
- **Главная** — акции, подборки блюд, категории и бизнес-ланч.
- **Каталог / меню** — список категорий и блюд.
- **Карточка блюда** — фотография, описание, цена и дополнительные ингредиенты.
- **Корзина/оформление заказа** — доставка или самовывоз, ресторан, адрес, промокод, время ожидания и оплата.
- **Карта доставки** — выбор/указание адреса на карте.
- **Уведомления** — акции и персональные предложения.
- **Личный кабинет** — заказы, адреса, личные данные, банковские карты.
- **Кэшбэк / программа лояльности**.
- **Информация о ресторане** — контакты, режим работы, FAQ, политика конфиденциальности.

##### **Доступные пользовательские действия**
1. Просмотр меню
Пользователь открывает приложение и просматривает меню ресторана. На главном экране представлены категории блюд, подборки и отдельные карточки товаров с фотографиями, описанием и ценой. Пользователь может перейти в нужную категорию и выбрать интересующее блюдо.

2. Формирование заказа
Пользователь открывает карточку блюда, выбирает необходимые дополнительные ингредиенты или варианты блюда и добавляет его в заказ. После этого он может изменить состав и количество товаров перед оформлением.

3. Заказ с доставкой
Пользователь формирует корзину → выбирает **«Доставка»** → указывает адрес → выбирает способ оплаты → подтверждает заказ.
Для определения адреса приложение может запросить доступ к геолокации. Пользователь также может сохранить адрес для последующих заказов.

4. Заказ с самовывозом
Пользователь формирует заказ → выбирает **«Самовывоз»** → выбирает подходящий ресторан → оформляет заказ → самостоятельно приходит в выбранный ресторан и забирает готовую еду.
Таким образом, самовывоз отличается от доставки тем, что пользователю не нужно указывать адрес получения — он выбирает конкретный ресторан.

5. Использование программы лояльности
Пользователь открывает раздел с программой лояльности и видит свой текущий кэшбэк, прогресс до следующего уровня и QR-код. Информация о кэшбэке отображается также на главном экране.

6. Получение персональных предложений
Пользователь получает уведомления о скидках, подарках и других акциях. Например, приложение может предложить скидку на заказ в день рождения. Пользователь может перейти из уведомления непосредственно к предложению.

7. Управление профилем
Пользователь может просматривать и изменять личные данные, управлять сохранёнными адресами и банковскими картами, а также просматривать историю заказов.

8. Просмотр информации о заказах
В разделе «Заказы» пользователь может посмотреть свои текущие и предыдущие заказы.

##### **Mobile-specific возможности**
**Геолокация**

**Push-уведомления**

**QR-код**

**Мобильная работа с оплатой**

#### 2) GloriaJeans

Приложение позволяет пользователю просматривать каталог одежды, искать и фильтровать товары, смотреть информацию о наличии и размерах, добавлять товары в корзину, оформлять заказ с доставкой или получением в магазине/пункте выдачи. ##### **Основные пользовательские сценарии**
- **Просмотр каталога и поиск товаров**  
    Пользователь открывает каталог, выбирает категорию и просматривает доступные товары. Также можно воспользоваться поиском и перейти к нужному разделу через категории.

##### **Основные пользовательские сценарии**
- **Выбор фитнес-клуба**  
    Пользователь разрешает доступ к геолокации → приложение определяет местоположение → показывает ближайшие клубы → пользователь выбирает подходящий клуб.
- **Просмотр расписания**  
    Пользователь открывает расписание → выбирает день → просматривает доступные тренировки, их время, продолжительность и тренера.
- **Запись на тренировку**  
    Пользователь выбирает тренировку → открывает её описание → проверяет информацию о занятии → записывается на тренировку.
- **Покупка абонемента**  
    Пользователь выбирает услугу → выбирает подходящий абонемент → просматривает его стоимость и условия → оформляет покупку.
- **Просмотр информации о клубе**  
    Пользователь выбирает клуб → просматривает его адрес, расстояние и другую информацию.
- **Получение уведомлений**  
    Пользователь получает push-уведомления о тренировках, изменениях расписания, акциях и других событиях клуба.
- **Управление личным кабинетом**  
    Пользователь просматривает личные данные, номер карты спортзала, информацию об абонементе и контактные данные.
- **Связь с фитнес-клубом**  
    Пользователь может позвонить в клуб, написать через Telegram, заказать обратный звонок или воспользоваться обратной связью.

## 2. Обзор существующих no-code/low-code платформ

### Таблица сравнения Bravo Studio и AppSheet

|                           | bravo                                              | appSheet                                                     |
| ------------------------- | -------------------------------------------------- | ------------------------------------------------------------ |
| тип                       | визуальный конструктор                             | конструктор на основе данных                                 |
| создание ui               | сам создаешь любой дизайн и переносишь в платформу | готовые типы экранов и блоки                                 |
| работа с данными          | через API и интеграции                             | работа с таблицами и базами                                  |
| навигация                 | связи между экранами                               | переходы через actions                                       |
| actions                   | действия элементов + API-запросы                   | действия с данными и интерфейсом                             |
| conditions                | условия по ответу API                              | условия через формулы                                        |
| workflows                 | цепочки действий после действий пользователя/API   | автоматизированные цепочки по событиям и данным              |
| mobile preview            | Bravo Vision на телефоне                           | просмотр в редакторе                                         |
| native capabilities       | камера, GPS, QR, push и др.                        | GPS, камера, QR, push и др.                                  |
| использование custom code | можно использовать JS / CSS / HTML                 | ограниченно, через внешние сервисы                           |
| сильные стороны           | дизайн и свобода интерфейса                        | данные, логика и автоматизация                               |
| ограничения               | сложная логика требует backend                     | меньше свободы в дизайне, даже в каком-то роде ее отсутствие |

### Какие идеи этих платформ могут быть полезны Tess?

#### Bravo Studio
- действия для кнопок и других элементов;
- переходы между экранами;
- условия «если → то»;
- последовательность действий;
- возможность связывать действия с элементами интерфейса.
#### AppSheet
- начало сценария с определённого события;
- условия и разделение сценария на разные варианты;
- действия с данными: добавить, изменить, удалить;
- объединение нескольких действий в одну цепочку;
- автоматический запуск сценариев.
